# Клиника медицинской косметологии

Сайт клиники: главная страница и отдельная посадочная страница на каждую
процедуру.

> **Сайт не готов к публикации.** Все данные о клинике, врачах, ценах и
> юридические реквизиты сейчас условные, а форма записи никуда не отправляет
> заявку. Перед запуском закройте [docs/CONTENT-CHECKLIST.md](docs/CONTENT-CHECKLIST.md).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run typecheck
```

## Стек

Next.js 15 (App Router), React 19, TypeScript, Tailwind v4, Motion, Lenis,
Phosphor Icons. Фотографии отдаются из `public`, внешних запросов за
изображениями нет.

## Структура

```
src/
  app/
    page.tsx              главная
    uslugi/[slug]/        посадочная страница процедуры, генерируется из данных
    api/booking/          приём заявки (пока не подключён к CRM)
    sitemap.ts robots.ts
  components/
    sections/             блоки главной
    BookingForm.tsx       форма записи, используется в диалоге и в контактах
    Photo.tsx             слот под фотографию
  content/clinic.ts       всё содержимое сайта
docs/
  REFERENCES.md           разбор референсов и откуда взялась дизайн-система
  CONTENT-CHECKLIST.md    что заменить перед запуском
  PHOTOGRAPHY.md          техническое задание на съёмку
```

Почти любое изменение текста, цены, врача или услуги делается в
`src/content/clinic.ts`. Новая процедура, добавленная в массив `services`,
автоматически получает страницу, попадает в меню, в прайс, в поиск и в sitemap.

## Дизайн-система

Разбор 21 референса из `public/screenshots` и вытекающие из него решения описаны
в [docs/REFERENCES.md](docs/REFERENCES.md). Коротко:

- **Шрифты.** Playfair Display на заголовках, Manrope на функциональном тексте.
  Выделение внутри заголовка только курсивом того же семейства.
- **Цвет.** Тёплые нейтрали из брифа плюс графит. Один зафиксированный акцент,
  приглушённый шалфейный, на всех интерактивных состояниях. Шампань только как
  материал на волосяных линейках.
- **Форма.** Пилюля на интерактивных элементах, 16px на карточках и медиа, 8px
  на полях ввода. Смешивать нельзя.
- **Движение.** Инерционный скролл, появление блоков при прокрутке, магнитные
  кнопки, наклон карточек. Всё выключается при `prefers-reduced-motion`.

Токены живут в `src/app/globals.css`.

## Доступность и адаптивность

Проверено на 390, 768 и 1440px: горизонтальной прокрутки нет, у всех
изображений есть альтернативный текст, у всех кнопок доступное имя, на странице
один `h1`. Форма записи валидируется в реальном времени, ошибки связаны с
полями через `aria-describedby`. Фокус виден всегда.

## SEO

Schema.org `MedicalClinic` на всех страницах, `FAQPage` на главной,
`BreadcrumbList` и `MedicalProcedure` на страницах процедур. Open Graph,
`sitemap.xml` и `robots.txt` генерируются из тех же данных.
