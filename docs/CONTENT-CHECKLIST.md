# Чек-лист перед запуском

На сайте нет ни одного настоящего факта о клинике. Всё содержимое ниже написано
для того, чтобы собрать и проверить вёрстку. **Пока этот список не закрыт,
публиковать сайт нельзя.**

Почти всё правится в одном файле: `src/content/clinic.ts`.

## Юридические реквизиты (блокирующее)

Значения намеренно записаны нулями, чтобы их нельзя было принять за настоящие.
Не заменяйте их «похожими на правду» цифрами: только данными из реестра.

- [ ] `legal.entity` - наименование юридического лица
- [ ] `legal.inn`, `legal.ogrn`
- [ ] `legal.license`, `legal.licenseDate`, `legal.licenseAuthority` - номер и
      дата лицензии на медицинскую деятельность
- [ ] Скан лицензии и приложений по адресу `/legal/license`
- [ ] Документы: политика конфиденциальности, согласие на обработку
      персональных данных, правила оказания платных медицинских услуг

Предупреждение «Имеются противопоказания. Необходима консультация специалиста.»
уже выведено в подвале и в форме записи. Убирать его нельзя.

## Данные клиники

- [ ] `brand.name` - сейчас условное имя LUMERA
- [ ] `brand.url` - боевой домен, от него строятся canonical, sitemap и Open Graph

      Заменить на реальных: ФИО, специализация, стаж, образование, сертификаты
