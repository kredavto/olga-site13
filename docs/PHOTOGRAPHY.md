# Съёмка

Сайт собран без стоковых фотографий. Каждое место под изображение сейчас
показывает подписанный слот с сюжетом и размером, а не серый прямоугольник и не
случайное лицо из стока. Это сделано намеренно: премиальная клиника не может
показывать чужие отретушированные лица, а пустая заглушка скрывает объём
оставшейся работы.

## Как подставить фотографию

1. Положите файл в `public/photo/`.
2. Передайте путь в компонент `Photo` через проп `src`:

```tsx
<Photo src="/photo/hero.jpg" seed="hero" label="Консультация врача" sizes="100vw" priority />
```

Заглушка исчезнет сама, `label` станет alt-текстом. Ничего больше менять не
нужно.

Для героя есть отдельный слот под видео: переменная `videoSrc` в
`src/components/sections/Hero.tsx`.

## Требования к серии

Материал должен выглядеть как одна съёмка, а не как подборка.

- Один фотограф, один комплект света, один день.
- Тёплая нейтральная гамма. Палитра сайта построена на топлёном молоке, кости
  и графите: холодный синий свет в кадре её ломает.
- Кожа без сглаживания. Текстура это то, что отличает медицинскую съёмку от
  рекламы косметики.
- В кадрах с пациентами лица либо анонимны, либо есть письменное согласие.
- Ни одной стоковой улыбающейся модели. Это прямое требование брифа.

## Вес

Целевой показатель PageSpeed выше 90 держится только при аккуратных исходниках.
Отдавайте фотографии в максимальном разрешении из таблицы, Next.js сам соберёт
AVIF и WebP под нужные размеры. Не загружайте кадры по 8 МБ прямо с камеры.
