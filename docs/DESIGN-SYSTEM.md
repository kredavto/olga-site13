# Дизайн-система

Оформление сайта построено на присланной системе. Все её значения перенесены в
`src/app/globals.css`, в блок `@theme`. Компоненты не используют цвета и шрифты
напрямую — только через токены, поэтому правка системы правит весь сайт.

## Цвет

| Роль | Значение | Токен системы |
| --- | --- | --- |
| Основной фон | `#fef9ef` | parchment canvas |
| Второй фон, чередование секций | `#f5eee1` | aged paper |
| Контуры, разделители | `#d1c9bf` | warm taupe |
| Тёмный фон под фотографией | `#2a2b2f` | ink |
| Основной текст | `#333333` | charcoal |
| Второстепенный текст | `#515151` | graphite |
| Акцент | `#b05a36` | terracotta seal |

Акцент один на весь сайт. Он несёт активные состояния (выбранная категория,
текущий кейс), заголовки на светлом фоне и главную кнопку. Как заливка он
появляется только на кнопке — именно поэтому во всех остальных местах он
дозирован.

**Терракота не работает на тёмном.** На ink она даёт 2,9:1 — ниже 3:1, которые
нужны даже крупному заголовку. Поэтому на фотографических секциях (первый экран,
блок на чёрном шёлке) акцентом служит светлый конец терракотового градиента
`#d4a68e`: на ink это 6,5:1.

Ash `#808988` из системы для текста не используется: на aged paper это 3,1:1
против нужных 4,5:1, а таких подписей на сайте больше семидесяти. Для них взят
graphite `#515151` — 6,8:1 на том же фоне.

## Шрифты

Система называет три лицензионные гарнитуры: **Financier Display**, **Ftbase**,
**Fragment Mono**. Их файлов нет, поэтому каждый стек называет нужную гарнитуру
первой, а дальше идёт ближайшая свободная замена с настоящей кириллицей:

| Токен | Система | Замена сейчас |
| --- | --- | --- |
| `--font-display` | Financier Display | Source Serif 4 |
| `--font-sans` | Ftbase | Inter |
| `--font-mono` | Fragment Mono | JetBrains Mono |

Чтобы перейти на лицензионные файлы, достаточно подключить их под этими именами
в `src/app/layout.tsx` — ни один компонент не обращается к гарнитуре напрямую.

Кириллица здесь не формальность: латинская гарнитура молча подменяется на
каждом русском заголовке, не давая никакой ошибки.

## Размеры и ритм

Базовый текст 16px, интерлиньяж 1,5, трекинг −0.37px — как в системе. Шкала
заголовков (34 / 45 / 64 / 80 / 88) применяется через `clamp`, потому что два
раздела обязаны помещаться в один экран и потому кегль там привязан к высоте
окна, а не задан числом.

Ширина макета — 1280px. Радиусы: кнопки 40px, карточки 24px, поля и теги —
пилюля, навигация 12px.

## Что осталось от прежнего оформления

Содержание не менялось: тексты, фотографии, структура разделов и все
взаимодействия те же. Изменились только цвет, шрифт, радиусы, ширина макета и
акценты.
